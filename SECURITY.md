# Security and private data

Do not submit credentials, institutional observations, private logs, real station catalogs or internal code through issues, pull requests or workflow artifacts. Use fictional SYN-prefixed examples for reproduction.

Report a sensitive concern privately to the repository owner through an agreed private channel. If no private channel is available, open a general contact request without including the sensitive details. Never post a suspected secret publicly.

This portfolio has no production service, database integration or secrets-dependent workflow. Synthetic controls do not certify a real source as complete or authorized.
