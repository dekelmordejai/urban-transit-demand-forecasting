# Public data boundary

This public portfolio contains newly authored prototype code, normalized illustrative contracts and invented SYN-prefixed fixtures. It includes no institutional extracts, internal calibration code, database names, connection strings, source documents or coordination records.

Only reviewed synthetic examples may be committed. Raw observations, real manifests, real station catalogs, private incident logs and institution-specific adapters belong in separately authorized storage and development environments. Even aggregate counts, file hashes and availability metadata may be sensitive in a real deployment. Public visibility is not permission to redistribute other people's data or code.

Ignore rules are convenience controls, not a security boundary. Review staged paths and content before publishing. CI runs on synthetic data with read-only repository permissions and no database secrets. Generated demo artifacts must retain their synthetic label.

Any future real-source integration needs an approved data contract, ownership/permission review, controlled access and retention, source reconciliation and explicit acceptance. External calibration requires verified rights and an interface before comparison; no such implementation is included here.

No open-source license is assigned to this portfolio snapshot. Dependencies retain their own licenses. Public access and a successful synthetic demo do not establish permission to reuse institutional material or prove real-world model accuracy.
