# Roadmap

| Stage | Evidence available | Next gate |
| --- | --- | --- |
| Foundation | Installable src package, tests, schemas and CI | Maintain reproducibility and clear scope |
| Synthetic data quality | Checksums, totals, missingness, catalog membership and revision selection | Validate any future source-specific mapping outside the public repository |
| Reference forecasting | Two statistical baselines and availability-aware synthetic evaluation | Real-source acceptance and a predeclared evaluation protocol |
| ML comparison | Planned | Add global ML only after leakage-safe features and reliable baselines |
| Uncertainty and reconciliation | Deterministic bottom-up sums exist; probability modeling planned | Validate quantile ordering, empirical coverage, nonnegativity and coherent distributions |
| Operational use | Planned | Independent validation, authorized inputs, monitoring and human decision review |

Potential work includes streaming ingestion, source-approved adapters, dynamic station scopes, leakage-safe incident-aware lags and model comparisons. None is represented as completed production functionality. A future existing-calibration comparison must verify the interface, rights and evaluation conditions first.
