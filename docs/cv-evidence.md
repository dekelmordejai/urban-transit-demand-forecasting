# Portfolio evidence

Supported description:

> Developed a modular Python prototype for urban transit demand forecasting, with versioned data contracts, reconciliation and completeness checks, automated tests and GitHub Actions CI. Built an offline reproducible synthetic demonstration using two seasonal statistical baselines, availability-aware evaluation and coherent station/line/system aggregation.

Spanish version:

> Desarrollé un prototipo modular en Python para pronóstico de afluencia de transporte público, con contratos de datos versionados, controles de conciliación y completitud, pruebas automatizadas y CI. Implementé una demostración reproducible con datos sintéticos, dos modelos estadísticos de referencia y evaluación temporal con agregación por estación, línea y sistema.

Evidence: source modules, tests, CI, the synthetic report, generated forecast rows, origin replay and SHA-256 checksums. This supports claims about implemented engineering and reproducibility. It does not support claims of a trained ML model, real-world accuracy, production users or operational optimization. Never present synthetic error percentages as institutional forecasting performance.
